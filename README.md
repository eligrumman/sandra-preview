# Sandra Leifer — artist portfolio preview

This repository hosts the artist website preview using GitHub Pages. It does not use a custom domain and does not change sandraleifer.com or the live book.

Source: [eligrumman/sandra-books, feat/immersive-artist-portfolio](https://github.com/eligrumman/sandra-books/tree/feat/immersive-artist-portfolio), directory `portfolio/`.

The Pages workflow checks out that source branch, validates the portfolio, and publishes only its static `portfolio/` directory. The source stays on its review branch. To refresh after source changes, use Actions → Publish artist preview → Run workflow.

Enable Settings → Pages → Source: GitHub Actions. Preview URL after deployment: https://eligrumman.github.io/sandra-preview/
